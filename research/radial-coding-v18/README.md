# Supporting research data for Exact radial coding limits for direction-normalized half-moons

Meshaal Mouawad, Mississippi State University. Research-data version V18, 24 November 2026.

[Download the verified research-data archive](HalfMoon_INS_Supporting_Research_Data.zip). The archive includes the radial-code recurrence, an independent numerical check, population-risk integrations, figure scripts, machine-readable results, and ten archived one-bit test-error counts.

The benchmark results include 14 exact alphabet sizes evaluated by interval arithmetic. The independent geometric calculation verifies all 14 and includes three scale checks. See the enclosed README for dependencies, units and instructions for reproducing the results.
